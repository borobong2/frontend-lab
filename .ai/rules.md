# Learning rules

- This is a learning lab. Preserve the learner's predictions, mistakes, and observations; never invent completed experiments or learning progress.
- Default to one question, one small experiment, and hints before full solutions. Implement a solution when explicitly requested.
- The vanilla UI is provided starter code. Mini React stages are learner work, not completed implementations.
- Use plain JavaScript and browser APIs for mini-react. Add dependencies only when an actual experiment needs them.
- Distinguish our educational model from actual React behavior; verify claims with official docs and an actual React comparison where appropriate.
- Use synthetic data. Separate old work evidence from new experiments.
- Verify changes using the manual checklist in the experiment README. Do not commit, push, or publish unless requested.

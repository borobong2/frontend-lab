# frontend-lab

프론트엔드가 해결하는 문제를 질문하고, 순수 JavaScript로 재현하고, 선택의 이유를 설명하는 개인 학습 공간입니다.

**첫 실험: [React를 왜 쓰는가](experiments/mini-react/README.md).** 동작하는 순수 JS 검색 화면을 출발점으로 제공합니다. 미니 React 구현과 학습 기록은 아직 진행하지 않았습니다.

## 바로 시작

이 레포 디렉터리에서 Python 3로 정적 서버를 실행합니다. 패키지 설치나 빌드는 필요 없습니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:4173/experiments/mini-react/ 를 엽니다. 종료는 Ctrl+C입니다. 포트가 사용 중이면 번호를 바꾸세요.

## 공부 방법

질문 → AI 없이 예상 → 필요한 공식 문서 → 작은 실험 → 예상과 실제 비교 → 내 설명 수정 → 다른 조건에서 재확인.

- 한 번에 사용자 흐름 하나와 실패 하나를 다룹니다.
- 90분은 시간 제한이지 이해 완료 기준이 아닙니다. 막히면 재현 범위를 줄입니다.
- 개념 회상은 AI·문서 없이, 독립 구현은 AI 없이 공식 문서 참조 가능으로 구분합니다.
- AI에는 먼저 반례·힌트·검증 질문을 요청합니다. 직접 확인하지 않은 설명은 사실로 기록하지 않습니다.
- [기록 양식](notes/TEMPLATE.md)을 복사해 날짜와 질문으로 저장합니다. 공개 글은 검증한 메모의 편집본이며 필수가 아닙니다.

## 현재 학습 지도

| 단계 | 실험 | 상태 |
|---|---|---|
| 0 | 순수 JS 검색·필터·정렬·메모 | 시작 코드 제공, 학습 미시작 |
| 1–2 | UI 설명 객체·렌더러·함수 컴포넌트 | 학습 과제 |
| 3–5 | 상태·DOM 재사용·key | 학습 과제 |
| 6–7 | 인스턴스별 useState·effect cleanup | 학습 과제 |

미니 React의 각 기능은 별도 정답으로 미리 구현하지 않습니다. 단계별 진행은 커밋으로 남기되, 비교가 필요한 예제만 별도로 보존합니다.

## 시간과 다른 작업의 연결

기존 주 12시간에서 FE 학습·면접 4.5시간을 사용합니다. 질문·실험 90분, 변형 75분, 설명 45분, 회상 30분, 기록 30분입니다. 지원 2시간·포트폴리오 3시간·백엔드 2.5시간은 유지합니다. 출퇴근 최대 5시간은 별도 선택 학습입니다.

이곳에서 원리를 실험하고, [Yggdrasil](https://github.com/borobong2/yggdrasil) 같은 실제 제품에 적용할 필요가 있는지 확인합니다. 블로그는 최대 격주 한 편, 편집 시간은 기존 포트폴리오 시간 안에서 씁니다.

## 검증

[첫 실험의 수동 확인 목록](experiments/mini-react/README.md#수동-확인)을 사용합니다. JS 구문은 아래 명령으로 확인할 수 있습니다.

```sh
node --check experiments/mini-react/src/main.js
```

공개 배포와 CI는 아직 구성하지 않았습니다.
